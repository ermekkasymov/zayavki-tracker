# Трекер контроля заявок

Excel-инструмент для ежедневного контроля статуса заявок: единая таблица, выпадающие списки, автоматическая подсветка просрочек и сводная статистика. Реализован строго по [PRD.md](PRD.md).

## Файлы

- **[Трекер_заявок.xlsx](Трекер_заявок.xlsx)** — готовый рабочий файл. Откройте в Excel и начинайте вносить заявки.
- **[build_workbook.py](build_workbook.py)** — скрипт на Python (openpyxl), которым сгенерирован файл. Позволяет пересобрать файл с нуля, если нужно изменить структуру.

## Структура файла

### Лист «Заявки»
Основная рабочая таблица: дата поступления, заказчик и поставщик (выпадающие списки), текущий статус, дата перехода на каждый из 5 статусов, автоматический расчёт дней на текущем статусе, комментарий. Запас 100 строк, стили и формулы уже протянуты.

Подсветка:
- своя заливка строки под каждый статус;
- жёлтая — если статус выбран, а дата для него не проставлена;
- красная — если заявка «висит» на статусе дольше порога просрочки;
- заявки со статусом «Отправлено» визуально гаснут (серый, приглушённый шрифт).

### Лист «Справочники»
Редактируемые списки заказчиков (10), поставщиков (3), статусов (5) и порог просрочки в днях. Изменения тут автоматически подтягиваются в выпадающие списки и подсветку на листе «Заявки» через именованные диапазоны.

### Лист «Сводка»
Количество заявок по каждому статусу, общее количество, количество просроченных, столбчатая диаграмма распределения по статусам.

## Пересборка файла

```bash
pip install openpyxl
python build_workbook.py
```
